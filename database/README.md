# Database

Database deo projekta koristi PostgreSQL.

## Tables

- users - korisnici
- owners - vlasnici lokala
- locations - WC lokacije
- reviews - ocene i komentari
- usage_records - korišćenje WC-a
- payments - plaćanja
- reports - prijavljivanje problema

Database/Admin deo je zadužen za strukturu baze, veze između tabela, testne podatke i saradnju sa backendom.
